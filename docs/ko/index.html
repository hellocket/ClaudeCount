설치

Claude Code를 쓸 수 있는 요금제(Pro, Max 등)가 필요해요.

  1. Claude Code 설치

    curl -fsSL https://claude.ai/install.sh | bash

  2. 터미널에서 로그인

    실행하면 브라우저가 열려요. 로그인하고 승인하면 끝.

    claude

  3. ClaudeCount 설치

    DMG 내려받기 ZIP 내려받기

    응용 프로그램 폴더로 옮겨서 열어요. 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기".

    Homebrew로 설치해도 돼요. 아래 두 줄을 순서대로 실행하세요.

    brew trust --cask hellocket/tap/claudecount
    brew install --cask hellocket/tap/claudecount

    최신 Homebrew는 공식이 아닌 tap의 앱을 처음 한 번 신뢰로 등록해야 해요. brew trust가 없다고 나오면 첫 줄은 건너뛰세요.

Anthropic의 공식 앱이 아니에요. 메뉴바 숫자 글꼴: Monoplex KR (SIL OFL 1.1)
